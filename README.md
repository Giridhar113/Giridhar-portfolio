# Portfolio v1.5

Job-ready personal portfolio for Giridhar Reddy Parlapalli, built as a static HTML/CSS website.

## About Repository

This repository contains the source code for my personal portfolio website. It is built to present my profile, skills, experience, projects, resume, and contact details in a clean, professional format for job applications and recruiter review.

The project uses simple static files, so it can be opened directly in a browser or deployed easily on platforms like GitHub Pages, Netlify, or Vercel.

## Overview

This portfolio highlights my professional summary, technical skills, experience, projects, resume, and contact information. It is designed for recruiter and hiring-manager review with fast navigation, clear project descriptions, and mobile-friendly layouts.
