Low-level programming and board control

Embedded Systems

A set of four embedded applications built on the ARM Cortex-M0+ KL25Z board, covering UART control, LED finite-state logic, 7-segment display output, and MBED workflows.

Tech Stack

Embedded C, MBED, KL25Z, ARM Cortex-M0+

Outcome

Developed hardware-control exercises that strengthen debugging and systems fundamentals.

Status

Completed embedded coursework/project set, public repository pending.

Problem

Embedded applications require reliable control logic, careful state handling, and confidence with board-level workflows.

Approach

  • Implemented UART control to practice serial communication.
  • Built LED finite-state behavior to practice predictable hardware states.
  • Worked with 7-segment display output for digital display control.
  • Used MBED and KL25Z board workflows to connect code with hardware behavior.

What I Learned

I gained stronger debugging habits and a better understanding of how low-level control logic translates into visible hardware behavior.
