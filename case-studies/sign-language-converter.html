Computer vision accessibility prototype

Sign Language Converter

A Python gesture-recognition prototype that converts 10 ASL signs into text using OpenCV and basic machine-learning concepts.

Tech Stack

Python, OpenCV, Basic ML, Computer Vision

Outcome

Built a prototype that demonstrates hand-sign detection and text output for a small gesture set.

Status

Prototype completed, public repository pending.

Problem

Sign-language tools need a bridge between visual gestures and readable output. This prototype explores a small practical slice of that accessibility problem.

Approach

  • Used OpenCV concepts to capture and process hand-gesture input.
  • Focused on a limited set of 10 ASL signs to keep the prototype measurable.
  • Converted recognized gestures into text output for a simple proof of concept.
  • Kept the project scoped as a learning prototype rather than a production accessibility tool.

What I Learned

I learned how computer vision projects depend on data quality, consistent input conditions, and clear limits around model accuracy.

Next Improvements

  • Add more gesture classes and better sample data.
  • Improve model evaluation and confidence display.
  • Publish cleaned code with setup instructions.
