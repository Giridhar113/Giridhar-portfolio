ECE and IoT systems project

IoT Home Automation

A 3-tier IoT system architecture for remote appliance control, simulated in Cisco Packet Tracer with six connected devices.

Tech Stack

IoT Architecture, Cisco Packet Tracer, Networking

Outcome

Modeled a remote-control flow across device, gateway, and user-control layers.

Status

Completed systems simulation, public repository pending.

Problem

Home automation systems need a reliable way for users to control appliances remotely while keeping device communication understandable and testable.

Approach

  • Separated the design into user-control, network, and appliance/device layers.
  • Modeled six devices in Cisco Packet Tracer to represent a small smart-home setup.
  • Focused on connectivity, control flow, and system-level reasoning.
  • Used the project to connect ECE concepts with product-style interface thinking.

What I Learned

This project strengthened my ability to reason about systems, device communication, and how hardware-focused ideas can be explained clearly to software teams.
